# Japanese Stock Data Analysis

[English](README.md) | [日本語](README.ja.md)

A Python and Streamlit application for Japanese stock-market data, technical and fundamental analysis, watchlists, portfolio views, and data export.

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

[Hosted application](https://japanese-stock-data-app.streamlit.app/).

## Features

The UI combines market overview, watchlists, portfolio summaries, symbol and theme search, moving averages, Bollinger Bands, RSI, MACD, stochastic indicators, and company fundamentals. CSV export and multiple-symbol comparisons support further analysis.

Provider availability, trading hours, API behavior, and dependency versions affect results. The Japanese guide retains the full indicator descriptions, examples, troubleshooting, and recorded output. Deployment-specific notes are in the repository's Streamlit guides.
